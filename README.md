# Dave — Selected work

A static portfolio showcasing two ongoing projects: Murmuration and Snowglobe.

Open `index.html` to view the page, or serve this folder with any static web server. No build step, accounts, database, API keys or paid services are required. The page uses Google Fonts with local system fallbacks.

## GitHub Pages

Upload this folder's contents to a new GitHub repository, keeping `index.html` at its root. In the repository's **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save. GitHub will show the published URL when deployment completes.

Use a repository named `YOUR-USERNAME.github.io` for a site at `https://YOUR-USERNAME.github.io/`, or another repository name for a project site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. All page assets use relative paths, so both work.

## Published content

- Murmuration: two recorded diagnostic replays of the actual C# simulation trajectories.
- Snowglobe: a Blender model study and three renders captured from the native iPhone prototype.
- Concise descriptions and project credits.

Neither native application's source or binary is included. No research archives, private account identifiers, signing information or private testing links are included.
